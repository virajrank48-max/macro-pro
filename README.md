# macro-pro

Project Summary: RBI Monetary Policy & Inflation Analysis
This project analyzes the monetary policy transmission mechanism in India by examining the lagged impact of the Reserve Bank of India’s (RBI) repo rate on inflation. Official monthly macroeconomic data was sourced directly from the Reserve Bank of India (RBI – DBIE).

Data & Methodology
Collected and cleaned RBI time-series data including repo rate and inflation indicators.
Handled missing values, standardized variable names, and converted dates into a time-series index.
Performed exploratory data analysis (EDA) and visualized macroeconomic trends.
Applied Ordinary Least Squares (OLS) regression with lagged repo rate variables to capture policy transmission delays.
Key Findings
Repo rate changes exhibit a statistically significant impact on inflation with a time lag.
The results align with RBI’s documented monetary transmission mechanism.
Low explanatory power is expected due to the multi-factor nature of inflation.
Tools & Technologies
Python (Pandas, Matplotlib, Statsmodels), Excel, Jupyter Notebook

Conclusion
The analysis highlights that monetary policy actions influence inflation with delays rather than instant effects. This project demonstrates the application of econometric methods and data analysis to real-world central banking and policy evaluation.
